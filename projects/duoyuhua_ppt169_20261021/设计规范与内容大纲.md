# 设计规范与内容大纲

## 一、项目信息

- 项目：duoyuhua（《多余的话》文献演示）
- 画布：PPT 16:9，1280 × 720
- 来源：瞿秋白《多余的话》，1935 年 5 月，据 PDF 排印本
- 页数：12
- 成品：原生可编辑 PPTX（真文本框、原生形状），适配本机 Office 2016

## 二、用户要求与落地

- 参考 5 个瑞士平面设计风格 PPT，采用瑞士国际主义：严格网格、左对齐、无阴影、无圆角、无渐变。
- 内容从《多余的话》PDF 中选取，保持原文语气，不虚构引文。
- 字体：大标题楷体（本机无华文楷体，使用系统楷体替代）；副标题等线加粗；正文华文中宋。
- 西文与数字：大字号数字用 `Trajan Pro Deck`；小字号数字与西文字母用 `Times Newer Roman`。
- 所有实际使用的字体家族和样式完整字符嵌入：楷体、华文中宋、等线 regular/bold、Calibri regular/bold/italic/boldItalic、Times Newer Roman、`Trajan Pro Deck`，共 6 个家族、10 个样式。Trajan Pro 因 PowerPoint 2016 的家族名限制，以 `Trajan Pro Deck` 同字形别名嵌入。
- 边栏色块加粗；开引号、括号做光学对齐；加入自动错峰淡入动画。
- 背景加入淡色曲线色块；色块面积更大、更协调；普通页以陶土、灰蓝、赭石、鼠尾草等莫兰迪色为准，只在极强情绪页撞色。
- 文字疏朗、不密集；每种文本类型固定一套字号与行距，跨页不随意变化。
- 用户无法查看 SVG，交付时必须同时提供 PNG 预览。

## 三、版式

- 页面 1280 × 720；左右页边距 80 / 1200；页眉线 96；页脚线 664；页码 692。
- 12 栏网格，栏宽约 74.7，栏间距 20；标题基线 176。
- 一律左对齐、右端参差；不使用居中、阴影、圆角、渐变。
- 左侧陶土边栏 44px（封面），右侧鼠尾草边栏 40px；页面内以大色块替代零碎装饰。

## 五、色彩

最高纲领：避免多色相互争夺注意力。普通页全部使用莫兰迪色系；只有在情绪极为强烈的“告别”和“终页”才允许撞色。

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 暖纸白 | `#F4F1E9` | 画布底色 |
| 墨 | `#232323` | 主文字 |
| 次级灰 | `#6E6A64` | 注释、页码 |
| 发丝线 | `#D3CEC3` | 页眉页脚线 |
| 陶土 | `#8E5750` | 主强调色 |
| 灰蓝 | `#5A707E` | 大色块、年份栏 |
| 赭石 | `#B49360` | 暖色块，配墨色文字 |
| 鼠尾草 | `#7D8D7B` | 次强调、目录第三项 |
| 灰紫 | `#7D6B72` | 备用强调 |
| 浅底 | `#F7F3EA` | 深色块上的反白文字 |
| 深底 | `#212426` | 终页 |

撞色只用于第 11、12 页：`#873A33` 深陶红、`#315553` 深青、`#C46A5E` 深底强调。

- 普通页每页最多两个莫兰迪主色，避免“三色旗”式平均分配。
- 赭石、鼠尾草上的文字用墨色；陶土、灰蓝上可用浅色，但小字必须保证对比度。
- 不用纯白、纯黑、荧光色；不用渐变填充。

## 六、图形语言

- 1–6px 硬边线；无圆角、无投影。
- 大色块保持原坐标和尺寸：陶土封面边栏、灰蓝整幅左栏、陶土统计块、赭石引文块、深陶红告别带、灰蓝年份栏。
- 大圆：直径 420–720px，部分出血到画布外，形成曲线边界。
- 大色块过渡采用两段式：主色 → `bgcurve_rim` 中间色弧带 → 底色；中间色弧带比主形大 14–26px 并略偏移，用同一条圆弧衔接，不再用会发灰的柔边。
- 背景曲线分三层：`bgcurve_rim` 中间色弧带、`bgcurve` 实体层、`bgcurve_contour` 等高线层。
- 浅色曲线保持清晰边界，叠加 2–3 圈 0.9px、约 24% 透明度的偏心等高线。
- 等高线要略偏心、略旋转，不能做成同心圆靶心；细节只用于局部，不铺满页面。
- 最终版取消独立增量曲线：第 2、6、10 页不叠加叹息线、张力线或黄金螺旋；曲线只作为背景色块的圆与弧，正文版式保持矩形硬边。
- 纯色大色块内部不叠加微型方块、色点或装饰性小色块；标记色只用于大色块、结构性分隔线和必要的信息编码，避免注意力失焦。
- 所有图形必须删除 `<p:style>` 中的主题效果引用；仅写空 `a:effectLst` 仍可能被渲染器套上投影，瑞士版式必须保持绝对平面。
- 第 11、12 页执行“决绝/终结”：禁用曲线，只用夸张矩形分割和极限放大的正圆；同时删除孤立小方块，所有装饰必须有结构作用。
- 超大数字作为版面锚点；数字与色块配合，不与正文抢读。

## 七、动画

- 全篇元素淡入 0.4s，按阅读顺序 0.06s 错峰，随页自动播放，不需要逐项点击。
- 共 173 个淡入效果，`clickEffect=0`，全部为 `withEffect` 的自动错峰；第 1、3 页删除微型装饰方块后各减少 1 个效果。
- 所有背景元素统一用 `bg` 前缀命名：`bgblock` / `bgcurve` / `bgcurve_rim` / `bgcurve_contour` / `bgbase` / `bgimage`。
- 动画生成脚本必须按前缀跳过 `bg*`，不能只判断三个精确名称；否则新增的等高线会逐圈淡入，破坏整页稳定感。
- 本机 PowerPoint COM 不稳定，动画不再用 COM 重新生成，而是由 `merge_legacy.py` 从已审计的旧版逐页迁移；先按文本、再按几何匹配形状，目标已删除的动画整块丢弃，其余重映射 `spid`。

## 八、字体嵌入与跨端

- PowerPoint 默认 `SaveAs(..., 24, -1)` 仍写入子集字体（EOT flags=5）。正式版必须再做完整字体替换，清除 `TTEMBED_SUBSET` 与 `TTEMBED_TTCOMPRESSED`。
- 完整嵌入后每个 `ppt/fonts/*.fntdata` 的 flags=0；楷体 28,562 glyphs，华文中宋 25,185，等线 regular/bold 29,624 / 29,593，Calibri 按样式 4,875–7,042，Times Newer Roman 759，`Trajan Pro Deck` 502。
- 完整嵌入后 PPTX 约 39 MB。字体全部来自授权允许嵌入（`fsType=8`）的 TrueType 文件，不改授权位。
- 本次为规避 PowerPoint COM 崩溃，`merge_legacy.py` 直接复用旧版已验收的 10 个完整字体部件、`embeddedFontLst` 和关系，再按新包关系重编号 `rId`。
- 每次重建后仍用 `verify_fonts.py` 验收：必须输出 `RESULT: PASS`，所有字体 `flags=0`，所有使用字体均为 `embedded`。
- 完整嵌入后不要再用 PowerPoint 普通保存，否则可能被重写回子集。
- PowerPoint 手机版、网页版、WPS 和聊天软件预览常忽略 PPTX 嵌入字体；本项目按用户要求不生成手机 PDF，跨端只用 PNG 预览。

## 十、图片落地

已插入 3 张真实图片，全部按 cover 方式裁切嵌入，不使用外链或假占位图。

- 封面：`images/qu_portrait_blur.png`，289×361（原 340×425 的 85%），放在右栏 800,190；左缘与图注、结构线对齐。图片整体不透明度 100%、外框硬边；只有与灰蓝圆重合的右上角做局部高斯模糊（9px，沿弧线 22px 渐变过渡），`prepare_images.py` 的 `blur_circle_zone()` 负责生成，源图为 `images/qu_portrait_print.jpg`。
- 封面页眉导视线 100→1140 仅作形状宽度：实线到 672，672→778 由 alpha 渐隐，778 之后完全透明；视觉上止于照片左侧、绝不贯穿图像。左端 4px 陶土结构线 778,190→778,551，图注“瞿秋白像”位于 800,571。灰蓝圆直径 470、圆心偏上，只作背景。
- 第 6 页：`images/qu_1935_print.jpg`，220×330，放在 950,100；图注“一九三五年六月十八日 · 汀州”，位于右侧留白，不进入正文与统计块。
- 终页：`images/monument_teal_gradient.png`，340×470，放在 780,130；青灰单调与深色页统一。四边做逐边 smoothstep alpha 渐变羽化（左 26 / 右 34 / 上 30 / 下 58），不是高斯模糊；边缘 RGB 同时向所在地底色过渡（深灰 `#212426` 或砖红 `#873A33`），底边随红圆做 20px 浅弧上抬，避免灰雾与暗带；图注“瞿秋白烈士纪念碑 · 福建长汀”。
- 原始图归档为 `*_original.jpg`；`prepare_images.py` 负责生成暖墨/青灰印刷调与终页渐变羽化 PNG，源图不覆盖。

- 图片用 `add_picture_cover()` 真正嵌入 PPTX，按 cover 方式裁切，绝不拉伸；支持 `focus_x` / `focus_y` 指定裁切重心。
- 黄金分割常量：`PHI=1.61803398875`，主侧 `0.618`，次侧 `0.382`。
- `golden_frames(side="right")` 在 1120px 内容区生成文字 / 图片框：图片约 692px，文字约 428px，中间 56px 空隙。
- 三种可用构图：
  1. 文字 38.2% + 图片 61.8%，图片高度按 3:2、5:3 或 8:5 裁切。
  2. 图片占 61.8% 以上甚至整幅出血，文字放在剩余窄栏或图片上的实色蒙版中。
  3. 图片底层 + 偏移 24–40px 的莫兰迪实色块 + 半透明同色蒙版，形成“图片—色块—文字”的交错图层。
- 蒙版保持硬边；背景只用实色与中间色弧带，不做柔边，避免正文区域发灰。
- 图片默认 100% 不透明、硬边裁切，不做羽化、减淡或虚化；封面肖像不使用任何柔边处理。
- 只有用户明确要求羽化时才做 alpha 羽化，且尺度是“局部”：单边、单角或弧形局部，不做四边均匀羽化，不用 Gaussian blur；羽化带透出真实底色，边缘颜色随所在地底色混合。整体不透明度仍保持 100%，不靠降低整体透明度制造过渡。
- 照片长边 1600–2000px、JPEG 85；透明素材用 PNG；图片命名 `image_content`，背景大图命名 `bgimage`。
- 图片不改变现有字体与行距；正文仍是真文本框，不把整页文字转成图片。

## 十二、排错经验

- PowerPoint 弹出 `0x00000000709E8092 ... 内存不能为 written`，连最小空白 PPTX 也崩溃，说明是 Office 进程/安装状态问题，不是演示文稿内容问题；不要继续用 COM 重试。
- 预览与导出改用 `@oai/artifact-tool` 的 `render_presentation.mjs`，本项目稳定输出 1× PNG 即可。
- `artifact-tool` 会提示 EOT 家族名与 SFNT 名不一致（楷体/KaiTi、华文中宋/STZhongsong、等线/DengXian）；这是旧版嵌入方式的已知现象，渲染与 `verify_fonts.py` 均正常，不必重做字体。
- `a:softEdge` 加在浅色块上会形成灰色晕圈，看起来像投影；改用 `bgcurve_rim` 中间色弧带做两段式过渡，边缘清晰但不生硬。
- `a:alpha` 的值是千分比：`24000` = 24% 不透明度，不是 24% 透明。
- 背景形状必须按 `bg*` 前缀统一跳过动画；只判断 `bgcurve` / `bgbase` / `bgblock` 会漏掉新层。
